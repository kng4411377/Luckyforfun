Trading Strategy Management API

Comprehensive REST API for algorithmic trading strategy management and IBKR integration

🚀 Quick Start

Get your API server running in 3 steps:

# 1. Start the API server
npm run api-server

# 2. Test the health endpoint
curl http://localhost:3000/health

# 3. View all strategies
curl http://localhost:3000/api/strategies

📊 Strategy Management

  • View all enabled and available strategies
  • Update strategy configurations dynamically
  • Enable/disable strategies on demand
  • Real-time configuration persistence

💼 Account & Holdings

  • Real-time portfolio positions
  • Account summary and balance
  • P&L tracking and analysis
  • Multi-account support

🔌 IBKR Integration

  • HTTP/HTTPS configurable connections
  • Automatic rate limiting
  • Session management
  • Paper and live trading support

🔧 Configuration Options

# API Server Configuration
API_HOST=localhost
API_PORT=3000

# IBKR Client Portal Configuration
IB_HOST=127.0.0.1
IB_PORT=5000
IB_USE_HTTPS=false # Use HTTP for localhost
IB_VERIFY_SSL=false
IB_RATE_LIMIT=1.0

📚 Example Usage

# Update momentum strategy allocation
curl -X PUT http://localhost:3000/api/strategies/momentum \
  -H "Content-Type: application/json" \
  -d '{"config": {"allocation": 0.4}}'

# Enable a strategy
curl -X POST http://localhost:3000/api/strategies/wyckoff-v2/enable

# Get account holdings
curl http://localhost:3000/api/account/holdings
